# Ashen Reaches — Godot 4 world prototype

A first-person dark-fantasy environment blockout. Open `project.godot` in Godot 4 and press F6 or F5 to run the main scene. No plugins or downloads are required.

- **WASD** move, **mouse** look, **Shift** run.
- **M** opens/closes the map. **Esc** releases the mouse; click the world to capture it again.
- Explore the central haven, Blackwood, Ashen Wastes and Broken Highlands. Three marked dungeon gateways and five monster placeholders are placed across the world.

This is a starting blockout: dungeon interiors, monster AI/combat, quests, audio and imported art are not implemented. The map is a schematic of the prototype, not a terrain generator. All visible geometry is generated by `world.gd`; dungeon entrances and monsters can be replaced with imported scenes as the project grows.

## Adding art later

Choose downloadable models on Sketchfab and verify the license and attribution for each specific model before using it. Import compatible glTF/GLB files into Godot. Mixamo supplies character animations; download the character and compatible animations, then import them into Godot and verify their rigs and animation names. Neither service's assets are included in this prototype.
