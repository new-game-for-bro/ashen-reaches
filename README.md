# Ashen Reaches

A playable first-person dark-fantasy prototype for Godot 4. Open `project.godot` and press F5.

## How to play

- **WASD** move, **mouse** look, **Shift** run.
- **Space** strikes a nearby hollow in front of you. Hollows pursue and attack when close.
- Defeat at least one hollow, then approach each of the three dungeon gateways and press **E** to cleanse its seal. Cleansing restores some health; cleanse all three to win.
- If your health reaches zero you return to the haven. Progress remains for the current run.
- **M** opens the world map. **Esc** releases the cursor; click the world to recapture it.

This is a prototype using generated placeholder geometry. The dungeon gateways are interactive seals rather than explorable interiors; there is no save system or sound yet.

## Art and animation

Sketchfab and Mixamo are planned sources for models and character animations. The Maw of the Void model is included as the hollow monster. Check each model's license and attribution, and verify the character rig and animation compatibility before importing. For example, [Maw of the Void by Yury Misiyuk](https://sketchfab.com/3d-models/maw-of-the-void-free-creature-asset-402848d2da654330bc9c3f23ec06cf8d) is a possible CC Attribution creature, but has not been imported or validated for this project.
