# Combat direction

The owner wants Ashen Reaches to play like a modern military shooter such as Call of Duty: Modern Warfare, adapted to mobile touch controls and its own setting. This is a design direction, not a statement that these features already exist.

Future work includes aiming and shooting, weapon feedback and reloading, cover and obstacle-aware movement, customizable mobile controls, and game-mode-specific rules for story, solo arena, battle royale and multiplayer. Preserve the existing modes and backend while introducing and testing combat incrementally. Networked combat needs server authority and validation before competitive online play.

Current status: existing prototype uses melee combat, and the online arena is a networking test without full networked combat. The Ancient Corinth fountain is the active prototype environment.
